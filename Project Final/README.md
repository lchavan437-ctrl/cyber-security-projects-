# 🌐 WAN with Ring Topology, OSPF, and Telnet

## 📌 Project Overview
This project demonstrates a Wide Area Network (WAN) using Ring Topology in Cisco Packet Tracer. It includes router and switch configuration, IP addressing, OSPF dynamic routing, and Telnet remote access.

## 🎯 Objectives
- Understand WAN configuration.
- Implement Ring Topology.
- Configure routers, switches, and PCs.
- Assign IP addresses and default gateways.
- Configure OSPF for dynamic routing.
- Enable Telnet for remote router access.
- Test network connectivity.

## 🛠️ Tools & Technologies
- Cisco Packet Tracer
- Routers and Switches
- PCs
- IP Addressing
- OSPF Routing
- Telnet Protocol

## ⚙️ Project Configuration
1. Created a network using Ring Topology.
2. Connected routers, switches, and PCs.
3. Configured IP addresses and default gateways.
4. Configured OSPF routing between routers.
5. Enabled Telnet remote access.
6. Tested connectivity between network devices.

## ✅ Expected Results
- Successful communication between connected networks.
- Dynamic routing through OSPF.
- Remote device access using Telnet.
- Proper WAN connectivity.

## 📚 Learning Outcomes
- Practical understanding of WAN.
- Knowledge of network topologies.
- Hands-on experience with OSPF.
- Understanding of remote network management.
